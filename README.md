### AI 产品经理 · 作品集 👋

软件工程本硕，4.5 年经验：一线互联网公司企业协作产品的 B 端服务端、在线教育公司三大业务中台（研发兼产品）；2025 年起独立完成多款 AI 产品 0→1。

我关心的不是「能不能把 AI 做出来」，而是能不能把模糊的大模型能力拆成**可观测、可回测、能止损**的产品链路。
